Herdr 是一个终端工作区管理器。它让真实的终端进程持续运行,并在其之上添加结构。

## 工作区

工作区是最顶层的项目容器。为每个仓库、任务或调查使用一个工作区。

工作区拥有标签页和窗格。它在侧边栏中的状态由内部的智能体汇总而来,让你一眼看出哪个项目需要关注。

## 标签页

标签页是工作区内的一种布局。用标签页来分隔不同视图,比如 `agents`、`logs`、`server` 或 `review`。

标签页可以通过 CLI 和 socket API 寻址。

## 窗格

窗格是一个真实的终端。Herdr 渲染终端输出,把输入传回进程,并在客户端分离后保留窗格。

窗格可以向右或向下分割。它们可以手动重命名、通过 CLI 读取、接收输入,以及被关闭。

## 鼠标 UI

展开的侧边栏默认使用项目树。每个工作区下列出智能体和普通终端窗格，包括其他标签页中的窗格。点击箭头折叠项目，点击项目名称切换工作区，点击子节点聚焦终端。项目旁的 `+` 在该项目内创建终端；右键项目可以创建终端或在新终端运行命令，右键子节点可以重命名、分屏或关闭窗格。命令通过正常的 shell 执行，可以直接输入个人启动命令，例如 `cdx` 或 `wb`。

每个终端占三行，内容居中，上下留白都可点击。项目标题以方括号包裹、绿色加粗，旁边显示可用的 Git 分支，子节点缩进，普通 Shell 使用次级颜色。手动窗格名称优先，否则显示 Agent 类型；项目内同类终端重复时附稳定窗格编号。不显示动态标题与终端 ID 副标题。右侧固定状态位：绿色加粗矩形点阵动画表示运行，`!` 表示等待输入，蓝色圆点表示完成未读，绿色实心圆点表示空闲，暗色横线表示未知。普通浏览只高亮当前窗格。右键选择「状态说明」可查看完整名称、项目、标签页、窗格 ID 与状态含义。仅可见且在线的运行节点在客户端有焦点、未打开对话框或终端弹窗时播放动画。折叠项目仍在空间允许时显示待处理和未读数量，包含隐藏的 worktree 子项目。长名称以省略号截断。

侧栏默认宽度为 30 列，可配置上限为 44 列；窄窗口会为主终端保留空间。底部「+ 新建项目」按钮进入现有新建流程。项目最后一个窗格关闭后，按终端已上报的当前目录生成名称和路径，收录到下方「最近项目」；无法取得终端信息时回退启动目录，独立于会话布局保存，服务器重启后仍保留，并按会话和机器隔离。点击记录在该目录新建终端，目录已有工作区时直接聚焦。此功能仅在服务器提供可选的 `project.list`、`project.open` 和 `project.forget` JSON 方法时显示。右键可查看完整路径或移除记录，移除记录不会删除文件；目录失效时保留记录并提示错误。同目录的其他工作区或自动补建 Shell 不隐藏关闭记录；成功重开才移出列表，失败保留。新关闭的项目会自动展开最近项目区并定位到最新记录。侧栏和选中背景使用较淡的中性色，保留文字配色。最近项目最多显示四行，可独立滚动和折叠，较矮窗口采用紧凑布局。

在工作区导航模式下（默认依次按 `Ctrl+b`、`w`），`Tab` 和 `Shift+Tab` 按可见项目与终端节点顺序切换，包含普通 shell；上下方向键保留工作区预览导航。键盘切换焦点时会展开目标项目并滚动到目标窗格。完成徽标沿用 Herdr 的客户端已读状态，展开任务树不会将完成标记为已读。设置 `ui.sidebar_layout = "split"` 可使用独立的工作区和智能体面板。紧凑侧栏和移动端布局保持原有行为。

Herdr 是鼠标原生的。你可以点击窗格、标签页、工作区和智能体,可以拖动分割边框、选择文本、使用右键菜单。下文的所有操作都可以用鼠标完成;按键绑定是可选的一层。

如果你偏好纯键盘操作,或者不想让 Herdr 捕获鼠标输入,可以禁用鼠标捕获:

```toml
[ui]
mouse_capture = false
```

## 智能体

智能体是 Herdr 在窗格内识别出的进程。Herdr 通过前台进程、屏幕清单和可选的集成来检测智能体。

智能体状态如下:

| 状态 | 含义 |
| --- | --- |
| `blocked` | 智能体需要输入、审批或决策。 |
| `working` | 智能体正在运行。 |
| `done` | 智能体已完成,你还没有查看。 |
| `idle` | 智能体已完成或在等待,并且已被查看过。 |
| `unknown` | Herdr 无法有把握地判断状态。 |

每个客户端独立记录它已显示的完成状态。在一个客户端查看完成状态，不会清除其他客户端的 Done 标记。CLI/API 使用服务器的已查看状态，因此不一定与某个客户端的标记相同；`idle` 和 `done` 都表示可以接受输入。

## 会话

会话是一个持久的 Herdr 服务器命名空间。默认的 `herdr` 命令连接到默认会话。

命名会话是彼此独立的运行时命名空间:

```bash
herdr session list
herdr session attach work
herdr session attach side-project
```

优先使用工作区。当你需要完全独立的窗格、socket 和持久化运行时状态时,才使用命名会话。

## 客户端与服务器

默认情况下,Herdr 以一个后台服务器加一个或多个已连接客户端的方式运行。

服务器拥有窗格和进程状态。客户端是连接到该服务器的终端 UI。

只有一个客户端连接时,所有标签页会像以前一样采用该客户端的尺寸。连接多个客户端时,每个客户端都可以查看自己的工作区和标签页。不同标签页会分别采用查看它们的客户端尺寸;客户端查看同一标签页时,最后聚焦、选择或操作该标签页的客户端控制其中窗格的尺寸。

用 `ctrl+b q` 分离客户端。服务器和智能体会继续运行。

如果想结束会话并停止其中的窗格,停止服务器:

```bash
herdr server stop
```

## 模式

Herdr 有终端模式、前缀模式和导航模式。

终端模式把按键发送给聚焦的窗格。前缀模式在按下前缀键后等待一个 Herdr 动作。导航模式是常驻的工作区导航界面。

按下前缀键 (默认 `ctrl+b`),再按一个动作键,比如 `c` 新建标签页,`w` 打开工作区导航。第一次接触前缀键的概念?参见[键盘](/zh-cn/docs/keyboard/)。
